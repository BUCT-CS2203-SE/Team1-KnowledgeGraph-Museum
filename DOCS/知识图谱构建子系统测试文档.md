# 海外中国文物知识图谱构建子系统测试文档

## 1. 测试概述

本测试文档针对海外中国文物知识图谱系统的四个主要模块进行验证：数据爬取、数据清洗与翻译、数据建模以及数据存储(MySQL和Neo4j)。
