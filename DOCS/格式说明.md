
### MySQL

分为两个表，`Arts_withimg`带图片，`Arts_withoutimg`不带图片

| 列名<br>      | 释义       | Type         | 列名<br>          | 释义      | Type         |
| ----------- | -------- | ------------ | --------------- | ------- | ------------ |
| **id**      | **唯一编号** | **int**      | Museum          | 现藏博物馆   | varchar(255) |
| Title       | 标题       | varchar(255) | PlaceOri        | 来源地     | varchar(255) |
| Artist      | 创作者      | varchar(255) | Classifications | 分类      | varchar(255) |
| Dynasty     | 年代       | varchar(255) | Medium          | 媒介      | varchar(255) |
| Credit      | 来源说明     | varchar(255) | *OnlyArtist*    |         |              |
| Dimensions  | 尺寸       | varchar(255) | main_start      | 主时代开始年份 | int          |
| ImgPath     | 本地路径     | varchar(512) | main_end        | 主时代结束年份 | int          |
| ImgUrl      | 网络链接     | varchar(512) | sub_start       | 次时代开始年份 | int          |
| Materials   | 材料       | varchar(255) | sub_end         | 次时代结束年份 | int          |
| Description | 描述       | text         | Periods         |         |              |
| Inscribed   | 铭文/题词    | text         |                 |         |              |

`OnlyArtist`和`Periods`是提取出来的字段，不用管。
`sub_start`-`sub_end`一般是`main_start`-`mian_end`的子集，不存在次年代就不存在，主年代同理。
